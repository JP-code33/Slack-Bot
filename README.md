# Slack-Bot

This is a Slack Bot which I have named it Curry Bot. It is a fast bot where you can input slash commands and it will give you the answer to that command. 

It is in the cloud so that it can run 24/7 and is not dependent on terminal on my end. 

The commands that are coded are:

1. /curry-bot-ping This check latency. This measures connection speed.
2. /curry-bot-catfact This gives out a cat fact.
3. /curry-bot-quote This gives out different quotes and the author name
4. /curry-bot-joke This gives out a joke

Those are the only commands that I have coded.

Thank you for testing my Curry Bot.
